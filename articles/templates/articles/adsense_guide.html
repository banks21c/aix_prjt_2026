구글 애드센스 신청 가이드

블로그에 광고를 붙여 수익을 만드는 절차 안내

NextFinUp이 회원님의 블로그(Blogger·워드프레스)에 AI 종목 리포트를 자동으로 발행해드리지만, 그 블로그에 광고를 달아 실제 수익을 만드는 건 별개의 절차입니다. 구글 애드센스(Google AdSense)에 사이트를 등록하고 심사를 통과해야 광고가 게재되기 시작합니다. 아래 순서대로 진행하세요.

시작하기 전에 — 블로그가 아직 없다면 먼저 블로그 자동 포스팅 연결 가이드부터 따라 Blogger 또는 워드프레스 블로그를 만들고 NextFinUp에 연결해주세요. 그리고 애드센스는 내용이 어느 정도 쌓인 사이트를 대상으로 심사하므로, 자동 포스팅을 켜둔 채 실제 글이 여러 건 쌓인 뒤에 신청하는 걸 권장합니다.

신청 전 체크리스트

  • 구글 계정 1개(블로그와 같은 계정이 아니어도 무방)
  • 회원님 소유의 블로그이며, 실제로 접속 가능한 상태(비공개·초안 아님)
  • 충분한 분량의 오리지널 콘텐츠 — 글이 1~2개뿐이거나 대부분 미완성 상태면 반려되기 쉽습니다
  • 워드프레스라면 사이트 소유권 확인용 코드를 <head>에 넣을 수 있는 권한
  • 만 18세 이상, 애드센스 결제 정보에 사용할 실제 주소

1. 애드센스 신청

공통

Blogger·워드프레스 공통 절차입니다.

  1. adsense.google.com 접속 → 시작하기

    google.com/adsense에서 "시작하기" 클릭 → 구글 계정으로 로그인.

    회원님 블로그의 주소(예: yourname.blogspot.com 또는 자체 도메인)를 입력하고, 국가/지역을 대한민국으로 선택합니다.

  2. 결제 정보 입력

    수익금을 받을 실제 주소·전화번호를 입력합니다. 이후 수익이 일정 기준을 넘으면 이 정보로 본인 확인(PIN 우편) 절차가 진행됩니다.

  3. 사이트 소유권 확인

    Blogger인 경우: Blogger 관리 화면 → 설정 → 기타 → 애드센스 항목에서 "연결하기" 버튼으로 자동 연동됩니다(코드를 직접 붙여넣을 필요 없음).

    워드프레스(자체 도메인)인 경우: 애드센스가 안내하는 확인용 <meta> 태그를 사이트의 <head>에 붙여넣어야 합니다. 워드프레스 테마 편집기로 직접 넣거나, Site Kit by Google 같은 플러그인을 설치하면 코드 편집 없이 연결할 수 있습니다.

    ℹ️ NextFinUp이 자동 발행하는 글의 HTML에는 애드센스 코드를 직접 넣어주지 않습니다 — 사이트 소유권 확인 코드는 반드시 블로그 자체의 테마/헤더에 삽입해야 합니다.

  4. 심사 대기

    제출 후 구글이 사이트를 검토합니다. 소요 기간은 사이트마다 다르며(수일~수 주) 구글이 별도로 안내하지 않으므로, 승인/반려 이메일을 기다리는 것 외에 확인할 방법은 없습니다.

2. 코드 구현 안내서

Google 공식 안내 요약

애드센스 코드를 페이지의 어느 위치에, 어떻게 붙여넣어야 하는지에 대한 Google 공식 가이드를 NextFinUp 회원 상황에 맞게 정리했습니다.

⚠️ 코드를 붙여넣기 전에 사이트가 애드센스 프로그램 정책을 준수하는지 먼저 확인하세요. 정책을 위반하면 Google은 언제든 사이트의 광고 게재를 중단하거나 애드센스 계정을 사용중지할 수 있습니다.

  1. 콘텐츠 관리 시스템(CMS)에 따라 방법이 다릅니다

    애드센스가 기본 내장된 CMS(Blogger, Hubpages, Weebly, Yola)는 관리 화면에서 연결 버튼만 누르면 됩니다 — 코드를 직접 붙여넣을 필요가 없습니다.

    플러그인이 필요한 CMS(워드프레스, Drupal, MediaWiki 등)는 헤더/푸터에 스크립트를 삽입해주는 플러그인을 설치해야 합니다. Google은 이런 플러그인을 직접 보증·지원하지 않지만, 광고 코드 자체를 바꾸거나 영향을 주지만 않으면 사용에는 문제가 없습니다.

    ℹ️ 워드프레스라면 WPCode – Insert Headers and Footers(300만+ 설치, 무료) 설치를 권장합니다. 설치 후 왼쪽 메뉴 Code Snippets → Header & Footer(화면 제목은 "Global Header and Footer")로 들어가서 Header 칸에 아래 코드를 붙여넣고 Save Changes를 누르면 사이트 모든 페이지의 <head>에 자동으로 삽입됩니다. client= 뒤 숫자는 회원님의 애드센스 코드에 있는 값으로 반드시 바꿔야 합니다. 플러그인 자체의 오류·업데이트 관련 문의는 Google이 아니라 플러그인 지원 채널로 해야 합니다.
    <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>

  2. 워드프레스: Site Kit로 한 번에 연결하기 (Google 공식 권장)

    Google이 직접 배포하는 무료 오픈소스 플러그인 Site Kit by Google을 쓰면 코드를 직접 붙여넣지 않아도, 사이트를 애드센스 계정에 연결하는 것만으로 모든 페이지(AMP 버전 포함)에 광고 코드가 자동 삽입됩니다. 애드센스뿐 아니라 애널리틱스·서치 콘솔·PageSpeed Insights 통계도 워드프레스 대시보드에서 함께 볼 수 있습니다.

    ⚠️ 앞서 WPCode 등으로 이미 코드를 직접 붙여넣었다면 Site Kit를 추가로 설치하지 마세요 — 같은 광고 코드가 두 번 삽입될 수 있습니다. 아래는 코드를 아직 넣지 않았거나, 처음부터 Google 공식 방법으로 설정하고 싶은 경우를 위한 대안입니다.

    1) 워드프레스 대시보드 → 플러그인 → 새로 추가 → Google Site Kit 검색 → 설치 → 활성화.

    2) 설정 시작 클릭 → 안내에 따라 구글 계정 연동.

    3) Site Kit 대시보드(또는 설정 탭)에서 애드센스 → 서비스 연결 클릭 → 안내를 따라 진행하면 코드 삽입까지 자동으로 끝납니다.

    4) 애드센스 화면에서 광고 → 자동 광고를 직접 켜야 실제로 광고가 게재됩니다 — Site Kit는 애드센스 계정 설정을 대신 바꿔주지 않습니다.

    ℹ️ EEA(유럽경제지역)·영국·스위스 방문자가 있는 사이트라면, 연결 시 나오는 "계정 활성화 즉시 광고 게재" 옵션은 EU 사용자 동의 정책 준수를 위해 선택 해제하는 걸 권장합니다 — 이 설정은 승인 후 애드센스 화면에서 언제든 바꿀 수 있습니다.

  3. HTML을 직접 편집하는 경우 주의사항

    Dreamweaver 같은 WYSIWYG(디자인 보기) 편집기를 쓴다면, 반드시 HTML 보기(코드 보기)에서 코드를 붙여넣어야 합니다. '디자인' 보기에 그대로 붙여넣으면 코드가 깨지거나 오류가 발생할 수 있습니다.

    붙여넣은 뒤에는 편집기가 코드를 임의로 수정하거나 줄바꿈을 바꾸지 않았는지 다시 확인하세요 — 이런 변형이 생기면 광고가 정상적으로 게재되지 않을 수 있습니다.

  4. PHP로 직접 만든 사이트

    애드센스 코드는 자바스크립트 선언을 포함하지만 사실상 순수 HTML이라 대부분의 PHP 사이트에도 그대로 붙여넣으면 동작합니다. 템플릿 구조에 맞게 원하는 위치에 그대로 삽입하면 됩니다.

3. 승인 후 설정

필수

심사를 통과했다는 이메일을 받은 뒤 진행하는 단계입니다.

  1. 자동 광고 켜기

    애드센스 관리 화면 → 광고 → 사이트 선택 → 자동 광고를 켜면, 광고 위치를 직접 배치하지 않아도 구글이 알아서 페이지에 광고를 삽입합니다. 처음에는 이 방식을 권장합니다.

  2. ads.txt 설정 (자체 도메인만 해당)

    Blogger(blogspot.com)는 자동으로 처리되지만, 워드프레스 등 자체 도메인은 사이트 루트에 ads.txt 파일을 직접 올려야 광고 수익이 정상 인식됩니다. 애드센스의 "사이트 소유권 확인" 화면에서 "Ads.txt 스니펫" 탭을 열면 회원님 계정 전용 내용이 나옵니다 — 그 내용을 그대로 씁니다.

    ⚠️ ads.txt가 없거나 내용이 틀리면 광고가 계속 붙어 있어도 수익이 정상적으로 집계되지 않을 수 있습니다.

    워드프레스는 ads.txt가 순수 텍스트 파일이라 위 1단계의 헤더 삽입 방식(HTML 붙여넣기)으로는 만들 수 없습니다. 이미 WPCode를 설치했다면 새 플러그인을 더 깔지 않고, 같은 플러그인의 Code Snippets → Add New 메뉴에서 PHP Snippet 타입으로 아래 코드를 추가해 해결할 수 있습니다(코드 안의 ads.txt 내용은 위에서 확인한 회원님 계정 값으로 바꿔야 합니다). 저장 후 Active로 켜는 것도 잊지 마세요.

    add_action('init', function () { $path = trim(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH), '/'); if ($path === 'ads.txt') { header('Content-Type: text/plain; charset=utf-8'); echo "google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0\n"; exit; } });
    ℹ️ 워드프레스 대시보드 → ads.txt 전용 플러그인(예: "Ads.txt Manager")을 따로 설치하는 방법도 있습니다 — 어느 쪽이든 결과는 같으니 이미 설치한 플러그인이 있는지에 따라 편한 쪽을 고르면 됩니다.

자주 발생하는 문제

"현재 사이트를 지원할 수 없습니다" / 반려됐어요

가장 흔한 사유는 콘텐츠 부족입니다. 자동 포스팅을 켜둔 채 최소 며칠~몇 주 더 글을 쌓은 뒤 재신청하세요. 재신청에 별도의 대기 기간 제한은 없지만, 반려 사유가 해소되지 않은 채 바로 재신청하면 다시 반려될 가능성이 높습니다.

사이트 소유권 확인이 계속 실패해요 (워드프레스)

보안 플러그인이나 캐시 플러그인이 <head>에 넣은 메타 태그를 걸러내는 경우가 있습니다. 브라우저에서 사이트 페이지 소스 보기(우클릭 → 페이지 소스 보기)로 해당 태그가 실제로 남아있는지 먼저 확인하세요.

승인은 됐는데 광고가 안 보여요

자동 광고가 켜져 있는지, 그리고 자체 도메인이라면 ads.txt가 정확히 올라가 있는지 확인하세요. 승인 직후에는 광고가 노출되기까지 다소 시간이 걸릴 수 있습니다.

블로그를 여러 개 연결하면 애드센스도 여러 번 신청해야 하나요?

애드센스 계정 자체는 1개면 충분합니다. 계정 승인 후 사이트 메뉴에서 다른 블로그 주소를 추가로 등록하면 되고, 새로 추가한 사이트도 별도 검토를 거칩니다.

Site Kit랑 WPCode(헤더/푸터 플러그인)는 뭐가 달라요?

Site Kit는 구글 계정으로 사이트를 애드센스에 직접 연결해 코드를 자동으로 심어주는 공식 플러그인이고, WPCode는 회원님이 직접 코드를 붙여넣는 범용 헤더/푸터 삽입 도구입니다. 어느 한쪽만 쓰면 됩니다 — 둘 다 설치하면 코드가 중복 삽입될 수 있습니다.

Site Kit 설정은 끝났는데 사이트에 광고가 안 보여요

다음을 순서대로 확인하세요: ① Site Kit 설정 화면의 애드센스 섹션에 "코드가 삽입되었습니다"라는 문구가 있는지, ② 애드센스 사이트 페이지에 이 사이트가 등록돼 있는지, ③ 애드센스 광고 페이지에서 자동 광고가 켜져 있는지. 세 가지 모두 정상이면 트래픽이 반영되기까지 다소 시간이 걸릴 수 있습니다.

Site Kit 말고 다른 연결 플러그인도 있나요?

Google이 공식 언급하는 대안으로 Insert Headers and Footers, Advanced Ads, Ad Inserter 플러그인이 있습니다. 다만 NextFinUp은 설치·설정이 가장 간단한 Site Kit(자동 연결) 또는 WPCode(코드 직접 붙여넣기) 둘 중 하나를 권장합니다.

편집기에서 HTML 소스 코드가 안 보여요

사용 중인 홈페이지 제작 도구(카페24, 아임웹, Wix 등)의 고객센터에 "HTML 삽입" 또는 "코드 보기" 기능이 있는지 문의하세요. 대부분의 도구는 이름은 달라도 비슷한 기능을 제공합니다.

그 밖에 CMS별 구현 방법이 더 궁금해요

"[CMS 이름] 애드센스 구현"으로 검색하거나, 애드센스 고객센터 커뮤니티에서 같은 CMS를 쓰는 다른 게시자의 사례를 찾아보는 것도 도움이 됩니다.
