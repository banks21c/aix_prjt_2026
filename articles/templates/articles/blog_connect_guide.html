블로그 자동 포스팅 연결 가이드

Blogger·텀블러·워드프레스 가입부터 마이페이지 연결까지

AI가 분석한 종목 리포트를 회원님의 블로그에 자동으로 발행하려면, Blogger·텀블러· 워드프레스 중 하나를 먼저 만들고 마이페이지에 연결해야 합니다. 세 플랫폼 모두 지원하며, 아래 순서대로 따라 하면 됩니다.

시작하기 전에 — NextFinUp에 로그인한 상태로 마이페이지 → "4. 자동 포스팅" 섹션에서 진행합니다. 이 섹션 상단의 "자동 포스팅 사용" 스위치도 켜져 있어야 실제 발행이 시작됩니다.

Blogger

구글 OAuth 연동

구글 계정만 있으면 별도 가입 절차 없이 바로 블로그를 만들 수 있습니다. 연결도 버튼 한 번으로 끝납니다.

  1. blogger.com에서 블로그 만들기

    blogger.com 접속 → 보유한 구글 계정으로 로그인 → "새 블로그 만들기" 클릭.

    블로그 제목, 주소(예: yourname.blogspot.com), 테마를 선택하면 바로 완료됩니다.

    ⚠️ 연결 전에 블로그가 최소 1개 있어야 합니다. 없는 상태로 연결을 시도하면 "연결 가능한 블로거 블로그가 없습니다" 오류가 뜨고 중단됩니다.

  2. NextFinUp에서 Blogger 연결

    마이페이지 → "4. 자동 포스팅" → Blogger 박스의 "이 플랫폼으로 자동 포스팅 사용" 체크 → "구글로 연결하기" 클릭.

    구글 동의 화면에서 Blogger 접근 권한을 허용하면 자동으로 마이페이지로 돌아오고, 연결됨 배지와 함께 블로그 주소가 표시됩니다.

    ℹ️ 블로그를 여러 개 가지고 있다면, 구글이 알려주는 목록 중 첫 번째 블로그가 자동으로 연결됩니다(직접 선택 불가). 원하는 블로그가 따로 있다면 다른 블로그를 정리한 뒤 연결하세요.

텀블러(Tumblr)

텀블러 OAuth 연동

텀블러 계정만 있으면 별도 가입 절차 없이 바로 블로그를 만들 수 있습니다. 연결도 버튼 한 번으로 끝납니다.

  1. tumblr.com에서 블로그 만들기

    tumblr.com 접속 → 계정을 만들면 가입과 동시에 기본 블로그가 하나 생성됩니다.

    ⚠️ 연결 전에 블로그가 최소 1개 있어야 합니다. 없는 상태로 연결을 시도하면 "연결 가능한 텀블러 블로그가 없습니다" 오류가 뜨고 중단됩니다.

  2. NextFinUp에서 텀블러 연결

    마이페이지 → "4. 자동 포스팅" → 텀블러 박스의 "이 플랫폼으로 자동 포스팅 사용" 체크 → "텀블러로 연결하기" 클릭.

    텀블러 동의 화면에서 접근 권한을 허용하면 자동으로 마이페이지로 돌아오고, 연결됨 배지와 함께 블로그 주소가 표시됩니다.

    ℹ️ 블로그를 여러 개 가지고 있다면, 텀블러가 알려주는 목록 중 첫 번째(기본) 블로그가 자동으로 연결됩니다(직접 선택 불가).

워드프레스

Application Password

설치형(자기 호스팅) 워드프레스 사이트가 필요합니다 — REST API(wp-json)와 애플리케이션 비밀번호 기능을 쓰는 사이트여야 합니다.

  1. 도메인 구매 → 웹호스팅 신청 → 연결

    Namecheap 같은 도메인 등록업체에서 원하는 도메인을 구매합니다.

    이어서 워드프레스가 자동 설치되는 매니지드 호스팅(예: Namecheap EasyWP)을 신청하면, 대부분 도메인과 자동으로 연결됩니다. 도메인과 호스팅을 서로 다른 업체에서 샀다면, 호스팅사가 안내하는 네임서버(Nameservers) 값을 도메인 관리 화면에 입력해줘야 연결됩니다.

    Namecheap 기준 EasyWP 신청 경로: namecheap.com → WordPress → Managed Hosting for WordPress.

    ℹ️ 구매한 지 좀 지나서 호스팅이 어디 있는지 기억이 안 난다면: Namecheap 기준 상단 메뉴의 "Hosting List"(cPanel 호스팅), 또는 EasyWP를 샀다면 Namecheap의 Apps 메뉴(namecheap.com/apps/dashboard)에서 EasyWP로 들어가면 dashboard.easywp.com에 있는 사이트 카드의 Manage/WP Admin 버튼으로 바로 접속할 수 있습니다.

  2. 애플리케이션 비밀번호 발급

    본인 워드프레스 사이트의 /wp-admin 로그인 → 사용자 → 프로필(본인 계정) → 페이지 맨 아래 "Application Passwords" 섹션으로 이동.

    이름을 입력(예: NextFinUp) → "새 애플리케이션 비밀번호 추가" 클릭 → 아래처럼 24자리 비밀번호가 한 번만 표시됩니다. 그 자리에서 바로 복사해두세요.

    예시 형식xxxx xxxx xxxx xxxx xxxx xxxx
    ⚠️ 워드프레스 로그인 비밀번호가 아닙니다. 로그인 비밀번호를 그대로 입력하면 인증이 거부되어 발행이 실패합니다.

  3. NextFinUp에 사이트 정보 입력

    마이페이지 → "4. 자동 포스팅" → 워드프레스 박스의 "이 플랫폼으로 자동 포스팅 사용" 체크 후 아래 세 칸을 채웁니다.

    사이트 주소https://내사이트주소.com
    계정 IDwp-admin 로그인 아이디
    비밀번호2단계에서 복사한 애플리케이션 비밀번호

    맨 아래 "저장" 버튼을 누르면 연결이 완료됩니다.

자주 발생하는 문제

저장은 됐는데 글이 안 올라와요 (워드프레스)

보안 플러그인이나 서버 방화벽이 REST API(/wp-json/) 요청을 막고 있을 수 있습니다. 브라우저에서 내사이트주소.com/wp-json/에 직접 접속했을 때 JSON이 정상적으로 보이는지 먼저 확인하세요.

"구글로 연결하기"를 눌렀는데 다시 연결 안 됨 상태로 돌아와요 (Blogger)

구글 동의 화면에서 취소했거나, blogger.com에 만들어둔 블로그가 없는 경우입니다. 1단계(블로그 만들기)부터 다시 확인해주세요.

"텀블러로 연결하기"를 눌렀는데 다시 연결 안 됨 상태로 돌아와요 (텀블러)

텀블러 동의 화면에서 취소했거나, tumblr.com에 만들어둔 블로그가 없는 경우입니다. 1단계(블로그 만들기)부터 다시 확인해주세요.

애플리케이션 비밀번호를 잃어버렸어요

워드프레스는 발급된 값을 다시 보여주지 않습니다. 같은 "Application Passwords" 화면에서 기존 항목을 삭제하고 새로 발급받아 마이페이지에 다시 입력하면 됩니다.

블로그 연결까지 끝났다면, 다음 단계로 구글 애드센스 신청 가이드를 참고해 블로그에 광고를 붙여보세요.
