# 전문가 상담 페이지 — "상담에서 지키는 12가지" 섹션

날짜: 2026-07-30
대상: `articles/templates/articles/expert_consult.html` (`/experts/`)

## 배경

종합자산관리사(PB)로서 갖추어야 할 자세 12가지를 사이트에 노출하려고 한다.
사이트에 기존 "덕목/가치관" 페이지나 섹션은 없다.

## 결정 사항

**위치** — `/experts/` 페이지 안, 프로필 카드(`상담을 맡는 전문가`)와 상담 신청
카드(`#consult`) 사이에 `.ec-card` 하나를 추가한다. 페이지 흐름이 *누가 상담하는가 →
어떤 자세로 하는가 → 신청하기* 로 이어져 전환에 가장 자연스럽다. 별도 페이지(`/principles/`)나
메인 랜딩은 후보에서 제외했다 — 전자는 유입 경로를 새로 만들어야 하고, 후자는 이미
다른 목적의 콘텐츠가 많아 12개는 무겁다.

**톤** — 원문의 설명조("~해야 합니다")를 고객에게 하는 약속체("~합니다")로 바꿔 쓴다.
상담 신청 폼 바로 위 섹션이므로 신뢰 형성에 직접 작용해야 한다. 프로필의 성명이 아직
`[[전문가 성명]]` 자리표시자이므로 "제가" 같은 1인칭 대명사는 쓰지 않고 주어를 생략한다.

**레이아웃** — 데스크톱 2열 그리드, 기존 `@media (max-width: 576px)` 브레이크포인트에서
1열. 아코디언(접기)은 배제했다 — 대부분의 방문자가 펼쳐보지 않아 내용이 읽히지 않는다.
원문에 없는 주제 분류를 새로 만들어 묶는 안도 배제했다(원문 왜곡).

## 범위

템플릿 한 파일만 변경한다. 모델·뷰·URL·마이그레이션·JS 변경 없음.

## 마크업 / 스타일

- 번호가 의미를 갖는 목록이므로 `<ol>`. `list-style: none` + CSS counter로 `01`~`12`를
  그리며, Safari가 `list-style: none`인 목록의 접근성 시맨틱을 버리므로 `role="list"`를 함께 준다.
- 번호와 제목은 한 줄에 흘린다(둘 다 `display: inline`). inline 요소는 세로 margin을
  무시하므로 제목 아래 간격은 설명문의 `margin-top`으로 준다.
- 설명문만 `Malgun Gothic` 계열을 쓴다. 윈도우 전용 폰트라 다른 OS에서는 fallback으로 떨어진다.

## 배경 이미지

카드 배경에 AI 어드바이저 이미지를 깐다: `articles/static/articles/expert-vows-bg.webp`.

- 원본 PNG 1.85MB는 페이지 배경으로 과하므로 WebP 품질 75로 재인코딩했다 (63.7KB, 768x1376 원본 해상도 유지).
- 이미지는 `.ec-vows-card::before` 레이어에 넣는다. 카드에 직접 배경을 주면 나중에
  투명도·필터를 걸 때 본문 글씨까지 같이 영향을 받는다. `::before`가 위치 지정 요소라
  본문을 덮으므로 `.ec-vows-card > *`에도 `position: relative; z-index: 1`을 준다.
- `background-position`은 `center top`. 세로로 긴 원본을 가로가 넓은 데스크톱 카드에
  `cover`로 채우면 `center` 기준에서는 인물의 머리가 잘린다.
- 이미지는 **투명도 없이 100%**로 깔고 `filter: saturate(1.25)`만 건다. 원본이 짙은 남색이라
  글자는 **전부 흰색**(h2·번호·제목·설명)으로 간다.

**접근성 메모.** 흰 글씨 기준 배경 대비의 중앙값은 8.0:1이지만, 홀로그램 인물의 밝은
하이라이트에 해당하는 **배경 픽셀의 18.5%에서 4.5:1 아래로 떨어진다.** 한때 어두운
`text-shadow`로 이를 보완했으나 사용자 지시로 제거했다(2026-07-30). 특정 항목이 읽기
어려우면 이미지 위에 어두운 반투명 레이어를 덧대거나 `filter: brightness()`로 밝은
영역을 눌러야 한다 — 글자색은 이미 흰색이라 더 밝게 할 여지가 없다.

## 같은 날 함께 진행한 페이지 개편

12가지 섹션을 넣는 김에 사용자 요청으로 `/experts/` 전반을 손봤다. 별도 스펙 없이
진행했으므로 결정과 이유만 여기 남긴다.

- **컨테이너 폭** `860px → 952px`. 카드 세 장을 92px씩 넓혔다. 카드마다 음수 마진을 주면
  좁은 화면에서 컨테이너 밖으로 삐져나오므로 컨테이너 `max-width`를 올리는 쪽을 택했다.
- **히어로**를 화면 전체를 가로지르는 띠에서 카드와 같은 폭의 박스로 바꿨다. 바깥
  `.ec-hero`가 `.ec-body`와 같은 `max-width`/`padding`을 갖고, 파란 박스는 안쪽
  `.ec-hero-box`에만 그린다. 이에 따라 카드를 띠 위로 끌어올리던 `.ec-body`의
  `margin-top: -36px`을 제거했다.
- **히어로 배경색** 로열블루(`#0d47a1→#1565c0`) → 딥 네이비(`#0a2647→#144272`).
  기존 조합은 본문 대비가 4.6:1로 AA 턱걸이였고, 딥 네이비는 8.27:1로 AAA를 넘는다.
- **프로필 카드 재구성.** 제목 `상담을 맡는 전문가`를 카드 상단 전체 폭에서 좌측
  `.ec-identity` 칸(215px)으로 내렸다. 오른쪽 박스가 카드 맨 위부터 시작해 사진 아래
  세로 여백이 줄어든다. 경력·보유 자격·수상경력·상담 분야를 2×2 박스 그리드로 배치했다.
- **항목 목록에서 `justify-content: space-between`을 걷어냈다.** 연도를 오른쪽 끝으로
  밀면 항목명과의 사이에 박스 안쪽 폭의 53%(최대 152px)에 달하는 빈 칸이 생겼다.
- 상담 철학 인용구를 삭제했다. 바로 아래 12가지 카드가 같은 내용을 풀어 쓰고 있다.
- `전문 분야` → `상담 분야`로 라벨 변경. 경력·자격·수상경력 실제 내용을 채웠다.
